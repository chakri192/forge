# UI & User Experience Guidelines

## UX Principles

1. **First-Glance Clarity**: Users should immediately understand their progress, active challenges, and current team status upon viewing the dashboard.
2. **Instant Micro-Feedback**: All interactive elements (buttons, task completion checkboxes, team selection) must provide visual feedback within 100ms.
3. **No Unnecessary Dialogs**: Prefer inline updates over blocking modal popups whenever practical.
4. **Mobile & Accessibility Ready**: Ensure text contrast meets WCAG AA standards and elements are touch-friendly.
