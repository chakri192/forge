# AI Agent Rules of Engagement

## Execution Rules

1. **Read Before Writing**: Always read existing documents in `docs/` before making architectural or code changes.
2. **Never Invent Requirements**: If a requirement or technical decision is unspecified, mark it as `Pending clarification` or ask the minimum required question.
3. **No Silent Changes**: Never change folder structures, API contracts, or database schemas without recording the rationale in `docs/project/decisions.md`.
4. **Beginner Mode Explanations**: Explain folder placements, service responsibilities, and design choices in simple language suitable for learning developers.
5. **Incremental Progress**: Implement tasks in small, verifiable steps. Verify runtime behavior before declaring success.
6. **Documentation Maintenance**: Update `docs/` whenever new facts or architectural choices are confirmed.
