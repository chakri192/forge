# Role Permissions Matrix

## Matrix Overview

The following matrix outlines access permissions for each role across core Phase 1 modules.

| Module / Action | Community Member | Community Lead / Admin |
| :--- | :--- | :--- |
| **Authentication** | Log In / Log Out | Log In / Log Out |
| **View Learning Activities** | Allowed | Allowed |
| **Create / Edit Activities** | Denied | Allowed |
| **Mark Activity Completed** | Self Only | Allowed for any member |
| **View Collaborative Challenges** | Allowed | Allowed |
| **Create / Edit Challenges** | Denied | Allowed |
| **View Teams** | Allowed | Allowed |
| **Join / Leave Team** | Self Only | Manage all memberships |
| **Browse Resources** | Allowed | Allowed |
| **Add Resource** | Allowed | Allowed |
| **Delete / Edit Resource** | Author Only | Allowed |
| **View Leaderboards** | Allowed | Allowed |
| **View Progress Dashboards** | Allowed (Self & Public) | Allowed (All) |
